# 部署指南（保姆级 · 给产品技术小白）

> 目标：让评委能在**公网打开一个网址**看到你的产品。
> 路径：**GitHub 存代码 → Vercel 连 GitHub 自动部署 → 拿到公网网址**。
> 你只需要做「注册 + 点几下」，代码推送和部署配置我都帮你弄好。

---

## 第一步：确认你有 GitHub 账号

1. 打开 https://github.com/signup
2. 用邮箱注册（用户名随便起，纯英文，例如 `chen-baoyan`）
3. 验证邮箱（去收件箱点链接）

如果没有账号，先做这步。有就跳过。

---

## 第二步：生成 GitHub 访问令牌（PAT）

这一步是给我用的，让我能把代码推上去（**你不用学 git 命令**）。

1. 打开 https://github.com/settings/tokens
2. 点 **Generate new token** → 选 **Generate new token (classic)**
3. Note 随便写，例如 `baoyan-deploy`
4. Expiration 选 **No expiration**（或 90 days 都行，反正今天就用）
5. 勾选 **repo**（点一下，下面子项会自动全选）
6. 拉到最底部，点 **Generate token**
7. **复制那串 `ghp_xxxxxxxx` 开头的字符**（只显示这一次！）

把这段令牌直接发给我。

---

## 第三步：把令牌给我，我来做剩下的

我拿到令牌后会一次性完成：

1. 创建公开仓库 `baoyan-ai-interviewer`
2. 把本地全部代码推送上去
3. 写好 Vercel 需要的配置

你什么都不用做，等我说「推好了」。

---

## 第四步：Vercel 部署（你点几下）

1. 打开 https://vercel.com/signup ，选 **Continue with GitHub**，授权登录
2. 登录后进入 Dashboard，点 **Add New** → **Project**
3. 在 Import Git Repository 里找到 `baoyan-ai-interviewer`，点 **Import**
4. Framework Preset 会自动识别成 **Next.js**，不用改
5. 展开 **Environment Variables**，填一行：
   - Name: `LLM_API_KEY`
   - Value: 你的 DeepSeek key（就是 `sk-xxxx` 那串）
   - 再加两行：
     - `LLM_BASE_URL` = `https://api.deepseek.com/v1`
     - `LLM_MODEL` = `deepseek-chat`
6. 点 **Deploy**，等 1–2 分钟
7. 部署完成后会给你一个 `https://baoyan-ai-interviewer-xxxx.vercel.app` 的网址

**这个网址就是交付物里的「公网 URL」。** 你自己点开试一遍，确认能跑通追问和报告。

---

## 常见卡点

- **Vercel 打不开 / 很慢**：用手机热点或换个网络再试。
- **Deploy 失败报 Building 错误**：把红色报错截图发我，我来修。
- **页面打开但问不出问题**：检查 Environment Variables 三个变量名有没有拼错（区分大小写）。
- **改了代码想重新上线**：把改好的文件发我，我推上去，Vercel 自动重新部署，不用再操作。
