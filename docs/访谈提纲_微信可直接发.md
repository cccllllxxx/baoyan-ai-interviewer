# 保研复试 用户访谈提纲（微信/电话，10–15 分钟）

> 铁律：**不提产品、不推销、不引导**。只问对方真实经历过的事。
> 每个问题都要追一句「能举个具体的例子吗」「当时你原话怎么说的」。
> 记录时**保留原话**，不要改写。

## 开场（30 秒）
「我在做一个关于保研复试准备的小调研，想听听你的真实经历，不推销任何东西。大概 10 分钟，方不方便？」

## 核心问题（按顺序问）

**1. 流程还原**
你复试的完整流程是怎样的？从进门到结束，每一环大概几分钟、有几个老师、问了什么类型的问题？

**2. 最痛的一刻（最重要）**
整个准备过程中，哪一件事让你觉得最没底 / 最崩溃？具体是哪一次、什么场景？

**3. 你当时怎么准备的**
为了准备复试，你实际做了哪些事？（追问：找人模拟过吗？找的是谁？模拟了几次？为什么不继续？）

**4. 现有工具的失败点**
你用过 AI（ChatGPT / 豆包 / 别的）帮忙准备吗？具体怎么用的？最后为什么没继续用下去？

**5. 反馈困境**
模拟完之后，谁给你反馈？反馈具体说了什么？你听完知道该怎么改吗？（追问：有没有人跟你说过「你这里答得不好」但没告诉你怎么改？）

**6. 被问穿的经历**
有没有哪个问题你当时完全没答上来 / 答完自己都知道很虚？是哪个点？你后来怎么补的？

**7. 付费意愿 / 时间投入**
为了复试，你愿意花多少时间和钱？（追问：如果有个东西能帮你练，你什么情况下会用？什么时候最需要？）

**8. 差异点**
你觉得专业面 / 英语面 / 科研经历追问 / 压力面，哪一段你最没把握？为什么？

## 收尾
「最后一个：如果有一个东西能帮你准备复试，你最希望它帮你解决刚才说的哪一件事？」

## 记录模板（每条访谈一段）

```
【对象】年级 / 目标院校专业 / 复试是否已结束 / 与你的关系
【时间】
【原话摘录】（至少 3 句，逐字）
【最痛的 1 件事】
【他用过的工具 + 为什么放弃】
【意外发现】（他没被问到但主动说的）
```

## 注意事项
- **同时发 8–10 个人**，不要等一个回完再发下一个 —— 周日早上回复慢，异步并行。
- 对方回得短，就语音/电话补 5 分钟。
- 3 份有效访谈即可开始聚类，不必等齐 5 份。
