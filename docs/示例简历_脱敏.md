### 为什么这份示例贴 demo 动线

- **用户群贴**：示例人物是**北京大学本科生跨校申复旦管院**——正是产品面向的「清北本科生」+「跨校保研」场景，与受访者 W 原型一致。
- **方向贴**：量化金融 + 券券行研 + 量化比赛 → 复旦管院量化金融与金融工程项目方向天然匹配。
- **有料可咬**：券商实习的「参与了一项消费行业比较研究」「主要负责数据处理和部分建模」——模糊的「参与 / 部分」会被考官逐层追问具体哪一步是你做的（经历真实性攻击清单 A）。
- **有方法可咬**：助研的「协助进行稳健性检验」「工具变量法」——会被追问 IV 的外生性假设、稳健性检验替换了什么（因果识别攻击清单 D）。
- **有行业可咬**：消费行业研究 → 实务型考官会问家电/白酒的龙头、上下游、地缘政治影响（受访者 W 原话追问）。
- **报告能挖真料**：「你的特质」能提炼出「有量化基础 + 消费研究实操」的人设，而非泛泛的「行业爱好者」。
