### 为什么这份示例贴 demo 动线

- **用户群贴**：示例人物是**北京大学本科生跨校申复旦管院**——产品面向「清北本科生」+「跨校保研」场景，与受访者 W 原型一致。
- **强度真实**：双实习（券商行研 + 量化私募）+ 助研带具体方法 + 课程论文 + 美赛 + 托福，对标清北本科生真实提交的个人陈述，不像应付差事。
- **方向贴**：量化金融 + 券券行研 + 量化私募 + Fama-French 论文 → 复旦管院量化金融与金融工程方向天然匹配。
- **有料可咬（经历真实性 A）**：券商实习「参与一项…比较研究，负责…部分建模」、量化私募「协助开发…参与…部分代码工作」——模糊的「参与 / 部分」会被考官逐层追问具体哪一步是你做的。
- **有方法可咬（因果识别 D）**：助研 IV「用地区间最低工资差异作外生冲击」——会被追问这个外生性假设成立吗、稳健性检验替换了什么。
- **有技术可咬**：Fama-French 论文「因子合成与 IC 检验」——会被追问因子怎么构造、IC 怎么算、有没有过拟合。
- **有行业可咬**：消费行业研究 → 实务型考官问家电/白酒的龙头、上下游、地缘政治影响（受访者 W 原话追问）。
- **报告能挖真料**：「你的特质」能提炼出「有量化基础 + 消费研究实操 + 因子建模能力」的人设，而非泛泛的「行业爱好者」。
