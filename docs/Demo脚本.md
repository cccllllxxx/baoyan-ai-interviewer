# Demo 录制脚本（3 分钟，一镜到底）

> 录制前：本地服务已在 http://localhost:3000 跑着（带最新 build）。
> 工具：Win+G 游戏栏 / OBS / 手机拍屏幕皆可。建议先空跑一遍对一遍流程。
> 总长 3 分钟，节奏留了余量，宁可快进也别拖。

## 录制流程

| 时间 | 画面 | 你说的话（旁白） |
|---|------|------|
| 0:00–0:15 | 黑屏标题卡 / 或直接进首页 | 「保研复试 AI 陪练。它的目的不是把面试者变成 AI，而是帮他发现自己的特质、更像自己地呈现——做照妖镜，不做提词器。」 |
| 0:15–0:35 | 首页：选项目（点「光华 MIM」或自定义）→ 选学术型 → 勾环节（亮简历深挖） | 「先选你的项目方向，系统会先把这个方向要什么样的人讲清楚，再据此考察你——这来自访谈里学长学姐说『AI 不懂这个项目要什么人』。」 |
| 0:35–0:55 | 传简历（拖一个 txt/docx 进去）→ 点生成人才画像 | 「简历直接传文件，跟真实交材料一样。」 |
| 0:55–1:15 | 展示人才画像（4 标准 / 3 淘汰项 / 最爱追问的点） | 「这是 AI 生成的找人标准，它会作为面试官评判你的依据。」 |
| 1:15–2:25 | 进入考场：第 1 问展示剧场开场「请进，坐…」+ 2–3 轮追问（可快进）→ 走到反问环节 | 「三位考官轮换，难度逐轮递增，超过真实面试强度。6 个环节走完后，考官会问你『有什么想问我们的吗』——这是真实复试的最后一步。」 |
| 2:25–2:35 | 反问环节：考生输入一个反问 → 考官简短回应 → 收尾「今天的面试就到这里」 | 「考生反问后，报告会自动生成。」 |
| 2:35–2:50 | 诊断报告顶部：「你的特质·怎么更像你自己」块 | 「报告最上面不是分数，是『怎么更像你自己』——从你刚才真实说过的内容里提炼你的人设、你真正有的优势、以及哪些话会被一眼看穿。」 |
| 2:50–2:58 | 下滑：被问穿的地方 + 知识地图 + 反问环节评价 | 「被问穿的地方逐条给该补的知识点和可检索关键词，不给话术；反问环节也会逐条点评加分还是减分。」 |
| 2:58–3:00 | 收尾卡：repo 链接 | 「github.com/cccllllxxx/baoyan-ai-interviewer」 |

## 没实现的功能怎么展示（诚实，不假装能跑）

未实现的想法（自定义项目冷启动、信心盲区、语音模式、模拟排名等）**不在视频里假装能用**——放在：
- Product Memo 第 4 段「下一步」
- README + docs/产品全景.md 的路线图

评委看到「知道边界、有路线图」是创业者思维加分项，不是扣分。

## 如果一定要可视化未来构想（可选）

我可以再做一个静态「未来构想」HTML 页（mockup 截图风格），你在视频末尾录 10–15 秒旁白「这些是下一步」。比 AI 生成视频保真、可控、不踩「造假」红线。需要就说。
