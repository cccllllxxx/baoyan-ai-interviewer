# ⚠️ 重要修正：产品定位必须调整

**原定位**：AI 复试**压力**面试官
**问题**：受访者Y 明确表示，保研复试中**压力面概率不大，学硕基本不可能**，学校老师「比起企业 hr 友好多了」。
如果产品叫做「压力面」，目标用户会觉得不对症 —— 她们怕的**不是被刁难，而是题目难度**。

**新的定位依据**（来自 受访者C，比「压力」更准确）：
> 「事实上面试考的比 mock 难」「我 mock 如鱼得水，但真实面试还是更难一些」「题目难度不一样」

**修正后的核心主张**：
不是「压力」，而是**难度对标与超标** ——
按目标方向的真实找人标准追问，**难度逐轮递增，最终超过真实面试强度**。

「压力型导师」保留为**可选风格之一**，不是产品定位本身。

### 对产品的意义（⚠️ 与 受访者C 直接冲突）

### 待用户拍板的三个问题

1. **目标用户是否收窄**：从「清北学生平级/向下保研」→「**冲外校 / 跨校 / 面试会深挖简历的项目**」？
2. **是否核实本院经管/金融系**：受访者L 明确说「不确定金融系有没有追问环节」。这条决定本院场景能否覆盖，需要用户找本院经管同学确认。
3. 若本院经管确实也追问 → 可覆盖；若不追问 → 明确排除本院场景，产品文案要写清适用边界。

## 受访者 E（语音转写，信息量最大）

**背景**：北大某院（含**金融系、风保系**）在读/已保研。同时参加过**复旦管院「量化金融与金融工程」**项目面试（含笔试）。准备最充分、观察最细的一位。

### 一、本院面试（金融系 / 风保系）

#### 关键原话

> 「金融系啊，还有风保系。他们都很强调在面试的时候问一些**不是课本上那种定义的问题**，就是可能会问你保险市场或者金融市场上到底发生了什么事情啊，然后你如何看待这个事情」
> 「你怎么看待这个市场的格局啊，还有说介绍某一个行业啊，这些就是**时事新闻**」
> 「一般通过看公众号，或者（金融系）可能需要看一些**研报**来了解」

> 「英语就是他给你一个类似于半张纸，上面印了一大段的英语，你需要**通读一遍，然后再逐句翻译**」
> 「这个英语一般就是专业性英语，而且**难度变化相当大**」（有一年考逆向选择很简单；今年风保系非常难）

> 「金融系它其实并不只局限于时事，它会考察一些**专业课内容**」
> 「我听说有的金融系学长表示，他其实很可能是**从一个题库里面出的题**」
> 「你就去找每年那个**保研手册**，把他们的问题全部收集起来……能收集多少就收集多少」
> 「然后你可以**再让 AI 根据这些问题来进行一些发散式的提问，还有追问什么的**，你就去把它相当于从一个问题延伸到一个大的知识点来了解它」

> 「（风保系）社会保险是一定要上的……刘新丽老师的风险管理学是建议上的」
> 「我抽到的主要就是社会保险的相关问题，还有风险管理学的相关问题。当然我后面换了一个问题……问我**人工智能对保险公司的影响**」

### 二、复旦管院（量化金融与金融工程项目）

#### 笔试

> 「这两个硕士项目会有**笔试**……（注：原转写含「考三个半小时、8 点半到 12 点」，用户复核原始语音后确认**未提及具体考试时间**，判定为转写误差，已剔除时长）」

#### 面试（3 面试官 vs 3 候选者）

> 「三个候选者需要在进入之前把一个姓名签儿贴在自己身上，在下面写着**名字，还有求职方向**。这个非常重要，因为复旦和高金那边的硕士项目都**非常重视个人的这种职业规划**……面试官一定会问这个问题」

> 「进去之后，3 个面试官会分别负责 3 种不同类型的问题」
> 「可能一个就是会问你**简历**，比如说问你简历上的经历，然后**深挖你这些经历背后的逻辑**。比如说你看的什么行业啊，他可能问你这个行业是什么逻辑，有可能是你的课题涉及到什么方向，然后他问你这个方向是什么东西」
> 「**而且你回答完这个问题之后，他大概率还会追问，就会继续往深处挖**」

> 「第二个面试官就会问**职业规划**。他首先会根据你的职业规划，还有你简历上呈现的**实习的匹配度**来问。因为假如和你实习的方向大相迳庭的话，他可能就觉得你是在骗人，就可能会稍微降一点印象分，并且会比较严肃地问你」
> 「你怎么看待现在这个行业，然后你认为它的前景是什么？还有你需要有什么样的品质、什么样的特性才会让你在这个行业里面具有独特性」
> 「问这个问题的人，他一般就是管院的校友，已经是业界从业者了，他就会真的比较了解」

> 「第三个……我遇到的是问**英语**的，然后也有可能会问一些专业课或者问一些 Tech」
> 「用英语问了我们三个一个问题……『假如你是一个企业中的管理者，那么你认为最重要的事情是什么？就是怎么管理员工？』……很宽泛，也没有标准答案」

> 「其他金融硕士项目的话，他会问到你的实习相关的。比如说，你实习做的是行业研究，那他就会问你这个行业的**龙头公司**是什么呀，这个行业的**上下游供货商**有什么呀，然后比如说**地缘政治风险**对于这个行业的影响」
> 「上海这些，他们**很看重实习**，就是需要做够足够多的实习……包括光华也是比较看重实习」

#### 面试技巧（⭐ 通用且具体）

> 「还有一点就是**不要抢着说**，他问你个问题之后，你可以说好的好的，或者说谢谢您，然后去**思考个三五秒**……再不急不慢地说出来」
> 「尽量要保证整个人的心境是比较平稳的……要强迫自己去冷静下来」
> 「包括在本院的面试的时候，也是他会给你相当的思考时间的」
> 「问英文问题的时候，没有指定回答顺序。假如你的同组有抢着说的话，你就可以让他们先说，然后你正好来构思一下」

### 三、读博 vs 读研

> 「想读博和读研……准备的差别很大。读博主要就是需要自己完成一个本研，就是本科生研究，然后写出一个独立的论文，或者是做出一个报告。然后在面试的时候，把这个报告讲给老师听，老师会针对报告去给你做一些指点」

### 四、对保研机构与 mock 的态度

> 「某些著名的保研机构，比如说保研声，我就是对他们一直都比较有意见」
> 「我也没有花钱去找别人模拟面试，但是我就是通过一些方法，我找到了他们的**面经**……然后我就去看看那些面经，在脑子里模拟了一下，没有找人给我 mock」

### 对产品的意义

| 发现 | 影响 |
|---|---|
| **复旦：问简历 → 深挖逻辑 →「回答完大概率还会追问，继续往深处挖」** | ⭐⭐ **强验证核心闭环**。「连续追问」不是我们脑补的，是真实面试行为 |
| **复旦/高金/光华极重视职业规划，且查「实习与规划的匹配度」** | 🔴 **新需求**：专业型（专硕）追问必须加**职业规划 + 匹配度拷问**。我们目前没有 |
| **她主动提出「让 AI 基于往年真题做发散式提问和追问」** | ⭐ **用户自己说出了我们的产品形态**。可支持：粘贴往年面经 → AI 发散追问 |
| **本院金融系「很可能从题库出题」，建议收集保研手册往年题** | ⚠️ **与 受访者C「没有题库」冲突**——但场景不同（本院 vs 外校） |
| **本院是抽题制**（抽到社保/风险管理，可换时事题） | ✅ **与 受访者L 一致**：本院抽题、不追问简历 → 排除本院的判断被二次验证 |
| **英语环节**：半张纸专业英语，通读 + 逐句翻译，难度波动大 | 🟡 独立环节。做窄原则下**暂不做**，可作「英文追问」候选 |
| **不要抢着说，思考 3–5 秒再答；本院也给思考时间** | 🔴 **与「节奏把控」合并**：节奏不只是答题时长，还包括**思考时间** |
| **上海/光华看重实习，会问行业龙头、上下游、地缘政治影响** | 🟡 强化专业型 prompt：行业理解要具体到「龙头 / 上下游 / 宏观风险」 |
| **读博 = 本研 + 论文 + 讲报告，与读研完全不同** | ✅ **确认聚焦硕士正确**，博士是另一套产品 |
| **对保研机构有意见；不花钱 mock，看面经自己脑内模拟** | ⭐ 现有付费服务不被信任；「脑内模拟」= 无人陪练的痛点，正是我们的机会 |
