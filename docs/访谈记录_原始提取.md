# ⚠️ 重要修正：产品定位必须调整

**原定位**：AI 复试**压力**面试官
**问题**：受访者Y 明确表示，保研复试中**压力面概率不大，学硕基本不可能**，学校老师「比起企业 hr 友好多了」。
如果产品叫做「压力面」，目标用户会觉得不对症 —— 她们怕的**不是被刁难，而是题目难度**。

**新的定位依据**（来自 受访者C，比「压力」更准确）：
> 「事实上面试考的比 mock 难」「我 mock 如鱼得水，但真实面试还是更难一些」「题目难度不一样」

**修正后的核心主张**：
不是「压力」，而是**难度对标与超标** ——
按目标方向的真实找人标准追问，**难度逐轮递增，最终超过真实面试强度**。

「压力型导师」保留为**可选风格之一**，不是产品定位本身。
