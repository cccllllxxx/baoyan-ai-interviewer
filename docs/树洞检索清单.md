# 北大树洞 检索清单（08:15–09:15，30–40 分钟封顶）

> 树洞是**匿名社区**，只能当**痛点线索来源**，不能当访谈证据。
> Memo 引用时必须标注可信度。别在这里陷进去 —— 40 分钟到点就停。

## 检索关键词（逐个搜，不要组合太复杂，树洞搜索很弱）

**第一轮 · 核心词**
`保研` · `推研` · `推免` · `复试` · `九推` · `夏令营` · `预推免` · `优营`

**第二轮 · 场景词（与核心词交叉看）**
`面试` · `被问` · `翻车` · `复盘` · `mock` · `模拟面试` · `套磁` · `导师`

**第三轮 · 情绪/细节词（最容易挖到原话）**
`答不上来` · `被问住` · `紧张` · `卡壳` · `尴尬` · `后悔` · `早知道`

## 你要捞的三类帖

| 类型 | 价值 | 举例 |
|---|---|---|
| **复盘贴** | 最高：有具体题目和当时反应 | "今天复试被问到 XX，我答的 YY，感觉凉了" |
| **求助贴** | 高：暴露真实焦虑点 | "下周面试，XX 这块怎么准备" |
| **吐槽/求助模拟** | 中：暴露供给缺口 | "有没有人愿意跟我 mock 一下" |

## 记录模板（每条一记，只抄原话，不要改写）

```
【来源】树洞 #编号（或大致日期）
【类型】复盘 / 求助 / 吐槽
【原话摘录】（至少 1 句，逐字保留）
【对应的痛点】
【可信度】高 / 中 / 低   ← 匿名、无上下文、可能是段子，必须标
```

## 三个必须警惕的偏差

1. **幸存者偏差**：发帖的绝大多数是"翻车的人"，顺利的人不发帖。别得出"大家都答不上来"的结论。
2. **情绪放大**：匿名社区天然放大焦虑，"完全答不上来"可能只是"有一句没答好"。
3. **无法追问**：帖子没有上下文，你不知道他是什么专业、什么水平。**所以树洞只能用来"生成假设"，验证必须靠你的微信访谈**。

## 收尾动作

捞到 8–15 条就停。回来后做一件事：**看哪些痛点在你的微信访谈里也出现了**。
两边都出现的 → 这才是真痛点，写进 Memo。
只在树洞出现的 → 标注为"匿名社区线索，未验证"。
