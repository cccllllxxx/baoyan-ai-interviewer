# 复试压力面 · AI 模拟面试官

给**保研复试**学生的 AI 压力面试官。

上传个人陈述后，AI 会像真实导师一样连续追问 8 轮，**专门咬住你回答里的漏洞不放**；结束后自动生成一份可执行的《追问诊断报告》——指出你被问穿的地方，并给出可以直接照着说的话术。

## 为什么不是直接用 ChatGPT

| | 裸 ChatGPT | 本产品 |
|---|---|---|
| 提问方式 | 你问一句它答一句，不会主动追问 | 主动连续追问 8 轮，抓住漏洞不放 |
| 态度 | 礼貌、会夸你、会给提示 | 不留情面，当场指出回答不成立 |
| 结束之后 | 什么都没有 | 结构化诊断报告 + 逐轮评分 + 可照抄的改法 |
| 追问依据 | 无 | 基于你真实简历里"没有量化、没有个人贡献、没有取舍"的地方 |

## 本地运行

```bash
git clone <本仓库>
cd baoyan-mock-interviewer
npm install

cp .env.local.example .env.local
# 编辑 .env.local，填入你的大模型 API Key

npm run dev
# 打开 http://localhost:3000
```

未配置 API Key 时，产品会使用**内置演示数据**跑通完整流程，方便直接体验交互。

## 环境变量

| 变量 | 说明 | 示例 |
|---|---|---|
| `LLM_API_KEY` | 大模型密钥 | `sk-xxx` |
| `LLM_BASE_URL` | OpenAI 兼容接口地址 | `https://api.deepseek.com/v1` |
| `LLM_MODEL` | 模型名 | `deepseek-chat` |

支持任意 OpenAI 兼容接口（DeepSeek、智谱 GLM、月之暗面 Kimi 等），切换只需改环境变量，无需改代码。

## 技术栈

- **Next.js 14**（App Router）— 前后端一体，API Route 隐藏 API Key
- **React 18** + 原生 CSS
- **大模型调用**：直接 `fetch` OpenAI 兼容接口，零 SDK 依赖
- **部署**：Vercel

## 项目结构

## AI 使用说明

- **产品设计**：用户访谈提纲设计、痛点聚类辅助 —— AI 辅助
