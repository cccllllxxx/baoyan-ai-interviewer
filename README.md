# 保研复试 · AI 模拟面试官（追问诊断陪练）

给**人文社科 / 经管类保研复试**学生的 AI 陪练 + 诊断报告。

先让 AI 生成该方向的真实「找人标准」（人才画像），再基于你的个人陈述**按 6 个真实环节（自我介绍→动机→科研贡献→专业方法→热点立场→综合抗压）逐环节深挖、专咬贡献度虚处**；每个环节内做自适应追问、直到问透或挖出薄弱点，结束后自动生成一份可执行的《追问诊断报告》——指出你被问穿的地方，并给出可以直接照着说的话术。

## 为什么不是直接用 ChatGPT

| | 裸 ChatGPT | 本产品 |
|---|---|---|
| 提问方式 | 你问一句它答一句，不会主动追问 | 按 6 环节逐层深挖、每个环节内自适应追问，抓住漏洞不放 |
| 追问依据 | 无 | 先生成该方向真实找人标准（人才画像），再基于你简历里"没有量化、没有个人贡献、没有取舍"的地方 |
| 难度曲线 | 永远温和，练完毫无压力感 | 随环节推进、同一环节内随追问加深而递增，最终超过真实面试强度 |
| 结束之后 | 什么都没有 | 结构化诊断报告 + 逐轮评分 + 可照抄的改法 |

## 在线体验

公网部署为加分项。按下方「本地运行」即可完整体验全部功能，**无需配置服务器公钥**；如需公网 URL，将本仓库连接 Vercel 即可自动部署。

## 本地运行

```bash
git clone https://github.com/cccllllxxx/baoyan-ai-interviewer.git
cd baoyan-ai-interviewer
npm install

cp .env.local.example .env.local
# 编辑 .env.local，填入你的大模型 API Key

npm run dev
# 打开 http://localhost:3000
```

未配置 API Key 时，产品会使用**内置演示数据**跑通完整流程，方便直接体验交互。

## 环境变量

| 变量 | 说明 | 示例 |
|---|---|---|
| `LLM_API_KEY` | 大模型密钥 | `sk-xxx` |
| `LLM_BASE_URL` | OpenAI 兼容接口地址 | `https://api.deepseek.com/v1` |
| `LLM_MODEL` | 模型名 | `deepseek-chat` |

支持任意 OpenAI 兼容接口（DeepSeek、智谱 GLM、月之暗面 Kimi 等），切换只需改环境变量，无需改代码。

## 技术栈

- **Next.js 14**（App Router）— 前后端一体，API Route 隐藏 API Key
- **React 18** + 原生 CSS
- **大模型调用**：直接 `fetch` OpenAI 兼容接口，零 SDK 依赖
- **部署**：Vercel

## AI 使用说明

本项目在 16 小时限时挑战中完成，AI 参与情况如下（关键决策均由本人拍板）：

- **产品设计**：访谈提纲、痛点聚类辅助由 AI 起草；用户群收窄（经管社科 / 跨校深挖）、访谈冲突取舍由本人完成
- **Prompt 工程**：面试官人格、追问准则、报告 JSON 结构由 AI 生成初稿，本人基于 5 份真实访谈逐条校准（如「经历真实性」列为最高优先级）
- **前端与后端代码**：Next.js 前后端由 AI 生成初稿，本人负责调试、构建排错与逐轮真机验证
- **方向决策**：人才画像环节、节奏把控、追问轮数等产品判断，均由本人与 AI 讨论后确定
- **本人独立完成**：用户访谈、全部产品决策、最终验收与 Memo 撰写
